# Conditions d’utilisation — Bot Discord

Version statique prête pour Vercel. Elle ne demande aucune installation, aucune commande de construction et aucun serveur.

## Déployer sur Vercel

1. Créez un nouveau dépôt GitHub et envoyez-y le contenu de ce dossier.
2. Dans Vercel, choisissez **Add New → Project**, puis importez ce dépôt.
3. Dans les réglages du projet, choisissez **Other** comme framework.
4. Laissez la commande de construction vide, puis cliquez sur **Deploy**.

Vercel sert directement `index.html` et met automatiquement le site en ligne à chaque modification du dépôt.

## Personnaliser

- Remplacez `BOT DISCORD` dans `index.html` par le nom de votre bot.
- Modifiez le bloc « Nous contacter » pour indiquer votre serveur Discord, une adresse e-mail ou votre site.
- Mettez à jour la date affichée après toute modification des conditions.
