Guide de démarrage

Installer Sentinel.exe sans te perdre dans les réglages.

Commence par les protections essentielles. Les réglages avancés peuvent attendre : ton serveur reste sous ton contrôle à chaque étape.

Ouvrir l’espace admin → Retour à l’accueil
  1. 01

    AJOUTER LE BOT

    Invite Sentinel.exe sur ton serveur.

    Ajoute le bot avec les permissions nécessaires pour lire les salons, envoyer des messages, gérer les rôles et gérer les salons.

  2. 02

    PLACER LE RÔLE

    Vérifie la position de Sentinel.exe.

    Dans les rôles Discord, place Sentinel.exe au-dessus de Vérifié et Quarantine. Le bot pourra alors attribuer ou retirer ces rôles.

  3. 03

    ACTIVER LA PROTECTION

    Ouvre le panneau Discord.

    Exécute /setup panel, crée la quarantaine, sélectionne ton salon de journaux et ajuste les seuils anti-raid si nécessaire.

  4. 04

    VÉRIFICATION

    Configure l’arrivée des membres.

    Depuis l’espace admin, choisis le salon de vérification et le rôle Vérifié. Le bot publiera ensuite son bouton automatiquement.

  5. 05

    TEST RAPIDE

    Vérifie que tout répond.

    Utilise /antiraid status, envoie un message de test dans le salon de logs et vérifie que le rôle de validation est bien attribué après un clic.

Avant de commencer

Les trois points importants.

  • Ne partage jamais le token Discord du bot.
  • Teste les protections sur un serveur calme ou avec un salon de test.
  • Garde toujours un rôle administrateur humain au-dessus du bot.
